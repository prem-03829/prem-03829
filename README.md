I enjoy working across the stack — from **frontend and UI/UX to APIs,

## Featured Projects

### Tank-Duels
**Full-Stack · Game Development · Production**

A browser-based turn-based artillery game where players
control tanks, adjust angle and power, account for terrain
and wind, and battle through custom-generated environments.

Built with a Canvas-based game engine, persistent game state,
authentication, REST APIs, and Supabase-backed player and battle data.

`JavaScript` `HTML Canvas` `Flask` `Supabase`

[Play Tank-Duels →](https://tank-duels-flax.vercel.app) ·
[View Source →](https://github.com/prem-03829/Tank-Duels)

### Inventory Management API
**Backend · REST API**

A Flask-based REST API for managing products, inventory levels,
stock updates, and audit history.

Includes request validation, proper HTTP semantics, partial updates
with PATCH, and structured API endpoints designed around real
inventory workflows.

`Python` `Flask` `REST API` `Database`

[View Source →](https://github.com/prem-03829/inventory-management-api)

### Bento Grid
**Frontend · Responsive Web Design · UI Showcase**

A responsive Bento Grid website built entirely with HTML and CSS,
created to showcase my frontend, layout, and responsive design skills.

Built from scratch without JavaScript, with a focus on visual
hierarchy, spacing, composition, and adaptable layouts across screen

`HTML` `CSS` `Responsive Design`
